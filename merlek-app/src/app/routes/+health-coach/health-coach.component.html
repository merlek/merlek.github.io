PROJECT 01 / IPHONE APP / IN DEVELOPMENT

Health Coach

A dependable workout journal.
A foundation for a broader coaching vision.

A personal software project exploring how a mobile app can support strength training while keeping the user in control of their records and next-workout decisions. Health Coach is a working name.

  • Angular
  • Ionic
  • Capacitor
  • Swift / HealthKit
PLATFORMNative iPhone app

SOURCEPrivate implementation

01 / THE PROBLEM

Workouts rarely follow
a perfect script.

Planned targets and actual results are different things. A set can be completed, missed, skipped, or adjusted. Supplemental work can progress independently of a main lift.

The journal keeps those distinctions explicit. It records what happened without silently turning every result into a new prescription.

02 / IMPLEMENTED TODAY

Log. Review.
Then decide.

A usable workout workflow

Customizable workout plans, per-set load and rep logging, failed and skipped sets, accessories, notes, history, and navigation back to an unfinished session.

Changes the user approves

Independent target review for main and supplemental schemes, manual overrides, and a percentage-deload preview. Applying a review is explicit; historical session targets stay frozen and stale reviews are rejected.

Portable records, clear provenance

LiftLog CSV summary import includes preview, invalid-row review, source details, and duplicate prevention. Imported summaries remain distinct from detailed sessions and do not silently change plan targets. JSON backup and restore provide another way to move and recover a journal.

NATIVE

Capacitor + Swift

Apple Health reads and protected on-device storage.

Make saving observable

Atomic local saves, visible failures, retry and export recovery, and a recoverable previous journal make persistence part of the user experience. No cloud account or upload is required.

Keep results and decisions separate

Independent progression rules and explicit application protect against unintended changes. Frozen session targets preserve the context of a completed workout.

04 / VALIDATION

Test the rules.
Rehearse the workflow.

Recorded validation includes 29 passing domain and import tests, production web and native iOS builds, and simulator workflows covering logging and relaunch, save failure and retry, target review, deloads, backup, CSV import, and navigation.

Native Apple Health reads and permission changes were tested on a physical iPhone. Simulator checks cover the newer workout, progression, and import flows; those checks do not establish physical-device validation for every feature.

Evidence snapshot: October 17, 2026. This is an actively developed personal app; the evidence covers these specific builds and test workflows.

05 / WHAT COMES NEXT

The journal works.
The coaching vision is still ahead.

AI coaching, lab and nutrition workflows, additional integrations, automatic missed-session scheduling, and richer charts remain roadmap ideas. The current app is a workout journal with deterministic review rules, rather than a finished AI coaching product.

About this public case study

The implementation remains private to preserve future commercial options. This showcase contains no private source or personal health records. The portfolio illustration uses fictional demo values and is not a screenshot of a personal journal.
